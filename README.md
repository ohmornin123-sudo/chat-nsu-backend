# CHAT-NSU Cloud Backend API
FastAPI backend service for Namseoul University Smart Campus Assistant, integrated with MongoDB Atlas cloud.

## Features
- `/health`: Health check
- `/notices`: Real-time announcements from MongoDB
- `/cafeteria`: Weekly cafeteria and Mulberry menus
- `/buses`: Commuter and shuttle bus schedules
- `/buildings`: Campus buildings and 5-digit room parser
- `/curriculum`: Intelligent Information & Communications Engineering courses
- `/chat/stream`: SSE streaming chatbot response
- `/graduation/check`: Graduation credit diagnostic calculation
